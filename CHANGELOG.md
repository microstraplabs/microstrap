# Microstrap v0.1.9

Microstrap 0.1.9 improves Roblox experience launching and adds an experimental built-in way to return to an earlier official Microstrap release.

## Highlights

- **Experience deep-link detection:** Opening a Roblox experience link with a place ID now opens Microstrap's game launcher for that experience.
- **Direct server joins stay direct:** Public server links with a `gameInstanceId` and private server links with an `accessCode` continue to launch as requested, without opening the game picker.
- **Beta downgrade option:** A new Microstrap settings section can download and install an earlier official release from GitHub. It clearly warns users before proceeding; use at your own risk.
- **GitHub release notes:** Full changelog text is included in the release description instead of relying on automatically generated commit summaries.
- **Chromium extension:** Extension metadata is versioned to 0.1.9 alongside the desktop app.

## Downloads
